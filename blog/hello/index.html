Starting a blog

28 Jul 2026 · meta

This is the first post. It exists mainly to show what a post looks like once it renders — headings, lists, code, quotes, all of it.

Writing a new post

Create a file in src/posts/ named YYYY-MM-DD-some-slug.md, give it front matter, write markdown underneath, then run the build:

python3 build.py --serve

The --serve flag opens a local preview at http://localhost:8000 so you can read it before anyone else does. Drop the flag to just build.

Front matter fields

Field Required Notes
title yes Shown in the list and as the page heading
date yes YYYY-MM-DD; falls back to the filename prefix
summary no One line, shown under the title in listings
tags no A YAML list, e.g. [python, notes]
draft no true keeps it out of the build until you’re ready

Drafts are the useful one. Set draft: true and the post stays invisible on the live site but still renders locally with python3 build.py --drafts.

When it’s ready, commit and push. GitHub Pages picks up the change within a minute or so.

Replace this post whenever you have something real to say — delete the file and rebuild, and it disappears cleanly.
